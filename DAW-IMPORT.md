# Importing Dark Techno MIDI

## Start here

1. Download and extract the MIDI ZIP from the catalog page.
2. Open a MIDI track in your DAW. Import a focused clip, a single role, or the combined arrangement. Choose the combined arrangement **or** its separate role files for a study; loading both duplicates the notes.
3. Assign an instrument to each pitched track and a compatible drum instrument or map to the drum track. MIDI contains note instructions, not recorded sounds.
4. Set the session to 132 BPM and 4/4, or choose your DAW's tempo-import option if you want the file's timing. Adjust the tempo creatively as needed.

## What was tested

On November 6, 2026, Ableton Live 12 Suite imported the four-bar `clips/dk02-melody-02.mid` as a MIDI clip. Live displayed its notes, a four-bar length, and a 4/4 signature. The tested file's SHA-256 was `2d7f7ac1d833855008f4bcd27e04d79e6b87ecf5a00459ea3360f713c8913ec8`.

In the same session, Live imported `midi/dk01-black-passage/dk01-black-passage-combined.mid` as six MIDI tracks with named role clips, each displayed over a 32-bar arrangement. The tested file's SHA-256 was `be79acfc2ae2ef5defa89329c451aca9364d0b4f919250c17b49e522b6f935c4`.

These checks do not prove compatibility with every file, DAW, plugin or device. No instrument playback, export round trip or human listening review was recorded. Live's MIDI import guidance: https://help.ableton.com/hc/en-us/articles/209068169-Understanding-MIDI-files
